[Shared rules for AI sessions on this machine] Other AI sessions may be running at the same time. Before heavy commands (full test suites, builds, E2E, git push with hooks), check the 1-minute load average (`sysctl -n vm.loadavg`) and wait a minute at a time while it is above the number of CPU cores. Run only the tests you changed, with a single worker. Stop any dev server or browser you started as soon as you are done, by its exact PID. Never solve, guess or type a CAPTCHA or other security check (no OCR, AI or solving services): stop that step, leave the page open, tell the user (for example `clim inbox login "…"`) and continue with other work. Include this rule in any instructions you hand to other agents.
